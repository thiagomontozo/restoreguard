# Frontend

The web client uses React, TypeScript strict mode, Vite, React Router, Tailwind CSS, and TanStack Query. Navigation covers overview, assets, sources, snapshots, policies, drills, evidence, reports, users, audit, and settings. The visual language is operational: text/icon/color statuses, restrained charts, readable tables, and useful empty states.

Asset 360 separates overview, backups, policies, drills, validations, evidence, and timeline. Drill detail shows persisted lifecycle events, objective measurements, assessment, qualitative confidence, and report export. SSE invalidates the current drill query as progress arrives.

Semantic headings/tables/nav, labels, keyboard focus rings, contrast, live alerts, and text status labels support accessibility. The UI stores no credentials/tokens in localStorage, uses no unsafe HTML, and does not assume hidden controls are security.
