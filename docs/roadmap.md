# Roadmap

**v0.1 — Recovery Assurance Core:** PostgreSQL logical recovery, local/S3 sources, Docker sandbox, typed validation, RPO/RTO, evidence, reports, auth/RBAC/audit, and a professional operational UI.

**v0.2 — Backup Ecosystem:** Restic and pgBackRest adapters, additional databases, richer notifications, stronger validation profiles, and more retention operations.

**v0.3 — Enterprise Recovery:** remote restore runner, Veeam adapter, cloud snapshots, distributed workers, advanced secret stores, and enhanced isolation/egress policy.

**v0.4 — Infrastructure Assurance Integration:** optional NetScope/InfraGraph context. Roadmap entries are proposals and must pass the same safety and evidence design review before implementation.
